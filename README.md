# ANUDIP CEO INDUSTRIAL VISIT — TATA Communication Gallery

A Streamlit photo gallery for the ANUDIP COE Industrial Visit to TATA Communication,
Kolkata, on 23rd September 2026.

## Project structure

```text
anudip_tata_gallery/
├── app.py
├── requirements.txt
├── README.md
└── images/
    ├── photo_01.jpeg
    ├── ...
    └── photo_14.jpeg
```

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Create a new GitHub repository.
2. Upload `app.py`, `requirements.txt`, and the complete `images` folder.
3. Open Streamlit Community Cloud.
4. Select your GitHub repository.
5. Select `app.py` as the main file.
6. Deploy.

No API key or secret is required.
